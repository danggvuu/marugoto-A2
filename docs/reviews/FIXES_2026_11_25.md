## Pipeline kiểm tra chính thức

```sh
python3 scripts/build_all.py
python3 scripts/build_all.py --check-only
python3 -m unittest discover -s qa/browser -p 'test_*.py' -v
```

- Build và check-only kiểm tra **69 trang HTML**, **87 file JS**, chạy bộ 103 regression cũ, các kiểm tra nội dung/phạm vi, 17 state recovery cases, 16 exam recovery cases, lesson/3D assertions và 4 Python build-helper tests.
- Bước lesson kiểm tra đầu ra A2.2 khớp generator bằng `--check-generated`, không chỉ kiểm tra nguồn trong memory.
- Browser suite cuối: **65/65 pass, không skip**, gồm 138 lượt tải 69 trang ở 360/1440px, kiểm tra JS error, HTTP local và tràn ngang; thêm luồng thực tế checkpoint/chấm bài/timeout và 3D/SVG.
- Test dùng context riêng, HTTP server local và chặn mạng ngoài, không dùng profile hoặc tiến độ cá nhân.
