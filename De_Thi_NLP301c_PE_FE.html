Câu 1 • 2.0 Điểm Trích xuất Hashtags duy nhất (Hashtags Extractor)
▼ Thu gọn

Viết hàm nhận vào một chuỗi văn bản và trích xuất tất cả các hashtag hợp lệ.

  • Hashtag bắt đầu bằng ký tự #.
  • Sau ký tự # chỉ gồm các chữ cái hoặc số (alphanumeric \w+).
  • Đưa về chữ thường (lowercase) và loại bỏ trùng lặp nhưng giữ nguyên thứ tự xuất hiện ban đầu.
Input "#AI and #nlp are future of #AI!"
Output ['#ai', '#nlp']
Python 3 
import re

def extract_hashtags(text: str) -> list:
    pattern = r'#\w+'
    raw_matches = re.findall(pattern, text)
    result = []
    seen = set()
    for tag in raw_matches:
        low_tag = tag.lower()
        if low_tag not in seen:
            seen.add(low_tag)
            result.append(low_tag)
    return result

# Kiểm thử:
print(extract_hashtags("#AI and #nlp are future of #AI!"))
# Kết quả: ['#ai', '#nlp']

▼ Thu gọn

Viết hàm trích xuất tất cả các từ đọc xuôi hay ngược đều giống nhau trong câu.

  • Không phân biệt hoa/thường khi kiểm tra (w.lower() == w.lower()[::-1]).
  • Bỏ dấu câu đi kèm; độ dài từ tối thiểu $\ge 2$ ký tự.
  • Giữ nguyên cách viết hoa/thường gốc của từ trong câu và thứ tự xuất hiện.
Input "Madam, did you see the racecar and kayak?"
Output ['Madam', 'racecar', 'kayak']
Python 3 
import re

def extract_palindromes(text: str) -> list:
    words = re.findall(r'[a-zA-Z]+', text)
    palindromes = []
    for w in words:
        if len(w) >= 2 and w.lower() == w.lower()[::-1]:
            palindromes.append(w)
    return palindromes

# Kiểm thử:
print(extract_palindromes("Madam, did you see the racecar and kayak?"))
# Kết quả: ['Madam', 'racecar', 'kayak']

import re
from collections import Counter

def words_frequency_at_least_k(text: str, k: int) -> dict:
    words = re.findall(r'[a-zA-Z0-9]+', text.lower())
    counts = Counter(words)
    filtered = {w: cnt for w, cnt in counts.items() if cnt >= k}
    return dict(sorted(filtered.items(), key=lambda item: item[0]))

# Kiểm thử:
print(words_frequency_at_least_k("apple banana apple orange apple banana", 2))
# Kết quả: {'apple': 3, 'banana': 2}

Python 3 
import re

def filter_words_by_length(text: str, min_len: int, max_len: int) -> list:
    words = re.findall(r'[a-zA-Z0-9]+', text)
    result = []
    seen = set()
    for w in words:
        low = w.lower()
        if min_len <= len(w) <= max_len and low not in seen:
            seen.add(low)
            result.append(w)
    return result

# Kiểm thử:

# ['quick', 'brown', 'jumps', 'over', 'lazy']
Câu 4 • 3.0 Điểm Đếm số lượng âm tiết / nguyên âm trong từ
▼ Thu gọn

Đếm số âm tiết dựa trên cụm nguyên âm liên tiếp a, e, i, o, u, y; loại bỏ 'e' câm ở cuối từ.

Python 3 
import re

def count_syllables(word: str) -> int:
    w = word.lower().strip()
    if not w:
        return 0
    # Bỏ 'e' câm ở cuối nếu không phải kết thúc bằng 'le'
    if w.endswith('e') and not w.endswith('le') and len(w) > 2:
        w = w[:-1]
    vowel_groups = re.findall(r'[aeiouy]+', w)
    return max(1, len(vowel_groups))

# Kiểm thử:
print(count_syllables("programming")) # 3
print(count_syllables("code"))        # 1

import re

def extract_positive_words(review: str) -> list:
    pos_set = {'good', 'great', 'excellent', 'amazing', 'fantastic'}
    words = re.findall(r'[a-zA-Z]+', review.lower())
    result = []
    seen = set()
    for w in words:
        if w in pos_set and w not in seen:
            seen.add(w)
            result.append(w)
    return result

print(extract_positive_words("The movie was amazing and the acting was excellent. Amazing story!"))

import re
from collections import Counter

def has_repeated_question(chat_text: str) -> bool:
    raw_questions = re.findall(r'([^?]+\?)', chat_text)
    cleaned = [q.strip().lower() for q in raw_questions if q.strip()]
    counts = Counter(cleaned)
    return any(cnt > 1 for cnt in counts.values())

print(has_repeated_question("Where is the library? What time does it open? Where is the library?")) # True
print(has_repeated_question("How are you? What is your name?")) # False

def extract_keywords(sentence: str) -> list:
    stopwords = {'the', 'is', 'and', 'in', 'on', 'at', 'to', 'a', 'an'}

📌 Nhóm 1: Tiền xử lý văn bản & Ngôn ngữ học cơ sở (Câu 1 – 10)
Tokenization, Type vs Token và Vocabulary Size
Token: Số lượng từ xuất hiện thực tế (kể cả lặp lại).
Type: Số từ vựng duy nhất (Vocabulary size \(|V|\)).
Ví dụ: "to be or not to be" có 6 tokens nhưng chỉ có 4 types: {'to', 'be', 'or', 'not'}.
Stemming vs Lemmatization
Porter Stemmer: Sử dụng thuật toán heuristic chặt bỏ đuôi (có thể sinh ra từ không có nghĩa, ví dụ: studies ➔ studi).
WordNet Lemmatizer: Tra cứu từ điển và phân tích từ loại POS để đưa về dạng nguyên thể từ điển (better ➔ good, studies ➔ study).
Định luật Zipf (Zipf's Law)
Tần suất xuất hiện \(f\) của từ tỉ lệ nghịch với thứ hạng \(r\) của nó trong danh sách tần suất:
\(f imes r pprox ext{hằng số } C\)
📌 Nhóm 2: N-gram Language Model & Perplexity (Câu 11 – 20)
Mô hình N-gram & Xác suất Maximum Likelihood Estimation (MLE)
Bigram: \(P(w_i | w_{i-1}) = rac{C(w_{i-1}, w_i)}{C(w_{i-1})}\)
Trigram: \(P(w_i | w_{i-2}, w_{i-1}) = rac{C(w_{i-2}, w_{i-1}, w_i)}{C(w_{i-2}, w_{i-1})}\)
Độ đo Perplexity (Đánh giá chất lượng mô hình)
\(PP(W) = P(w_1, w_2, \dots, w_N)^{- rac{1}{N}} = \sqrt[N]{ rac{1}{\prod_{i=1}^N P(w_i | w_{i-1})}}\)
Lưu ý vàng khi làm bài trắc nghiệm: Mô hình ngôn ngữ càng tốt thì Perplexity càng THẤP!
Các kỹ thuật làm mượt (Smoothing)
Laplace (Add-1): Thêm 1 vào tử số và \(|V|\) vào mẫu số:
\(P_{ ext{Laplace}}(w_i | w_{i-1}) = rac{C(w_{i-1}, w_i) + 1}{C(w_{i-1}) + |V|}\)
Kneser-Ney Smoothing: Kỹ thuật làm mượt N-gram hiệu quả nhất, tính toán dựa trên xác suất tiếp nối (Continuation Probability).
📌 Nhóm 3: POS Tagging & Hidden Markov Model (HMM) (Câu 21 – 30)
Cấu trúc mô hình HMM
- Trạng thái ẩn \(S\): Các nhãn từ loại (POS tags: Noun, Verb, Adj...).
- Chuỗi quan sát \(O\): Các từ thực tế trong câu.
- Ma trận chuyển trạng thái \(A\): \(P(t_i | t_{i-1})\).
- Ma trận phát xạ \(B\): \(P(w_i | t_i)\).
Thuật toán Viterbi & Forward-Backward
Viterbi: Sử dụng quy hoạch động để tìm chuỗi nhãn ẩn tối ưu nhất có độ phức tạp thời gian \(O(|S|^2 imes T)\).
Forward-Backward: Dùng trong thuật toán Baum-Welch (EM) để huấn luyện tham số HMM khi không có nhãn.
📌 Nhóm 4: Phân loại văn bản, TF-IDF & Word2Vec (Câu 31 – 40)
Trọng số TF-IDF
\( ext{TF-IDF}(t, d, D) = ext{TF}(t, d) imes \log\left( rac{|D|}{|\{d \in D : t \in d\}|} ight)\)
TF đo tần suất từ trong tài liệu, IDF phạt các từ phổ biến xuất hiện ở hầu hết tài liệu.
Word2Vec: Skip-Gram vs CBOW
CBOW (Continuous Bag-of-Words): Dự đoán từ trung tâm dựa vào ngữ cảnh xung quanh. Huấn luyện nhanh hơn trên tập dữ liệu lớn.
Skip-Gram: Từ từ trung tâm dự đoán các từ ngữ cảnh. Hoạt động cực tốt với tập dữ liệu nhỏ và biểu diễn tốt các từ hiếm (rare words).
Tối ưu hóa tính toán: Negative Sampling và Hierarchical Softmax.

📌 Cú pháp học & Cây cú pháp (Syntax & CKY Parsing)
Chomsky Normal Form (CNF) & Thuật toán CKY
Mọi luật sinh trong CNF chỉ có 2 dạng duy nhất: \(A ightarrow BC\) (2 non-terminals) hoặc \(A ightarrow a\) (1 terminal).
Thuật toán CKY: Phân tích cú pháp Bottom-up dựa trên quy hoạch động với ma trận tam giác, độ phức tạp thời gian là \(O(n^3 \cdot |G|)\).
Dependency Parsing (Cây quan hệ phụ thuộc)
Gán nhãn trực tiếp quan hệ ngữ pháp giữa từ chủ đạo (Head) và từ phụ thuộc (Dependent): nsubj (Chủ ngữ), dobj (Tân ngữ trực tiếp), amod (Tính từ định ngữ).
📌 Dịch máy & Đánh giá mô hình sinh văn bản (BLEU & ROUGE)
Độ đo BLEU Score (Bilingual Evaluation Understudy)
Được dùng chủ yếu cho Dịch máy (Machine Translation), đo Modified N-gram Precision kết hợp hình phạt câu ngắn Brevity Penalty (BP):
\( ext{BLEU} = ext{BP} imes \exp\left(\sum_{n=1}^N w_n \log p_n ight)\)
Nếu độ dài ứng viên \(c \le r\) (độ dài tham chiếu), \( ext{BP} = \exp(1 - r/c)\).
Độ đo ROUGE (Recall-Oriented Understudy for Gisting Evaluation)
Dùng chủ yếu cho Tóm tắt văn bản (Text Summarization). Trọng tâm đo Recall (mô hình bắt được bao nhiêu % nội dung cốt lõi của bài tóm tắt chuẩn).
📌 RNN, LSTM & Cơ chế Attention / Transformer
Hạn chế của RNN truyền thống
Hiện tượng Vanishing Gradient (triệt tiêu gradient) khiến RNN không học được các phụ thuộc tầm xa (Long-term dependencies) và không tính toán song song được.
Cấu trúc 3 cổng của LSTM
1. Forget Gate \(f_t\): Quyết định giữ hay quên thông tin từ trạng thái trước \(C_{t-1}\).
2. Input Gate \(i_t\): Quyết định nạp thêm thông tin mới nào vào bộ nhớ cell.
3. Output Gate \(o_t\): Quyết định xuất trạng thái ẩn \(h_t\).
Scaled Dot-Product Attention trong Transformer
\( ext{Attention}(Q, K, V) = ext{softmax}\left( rac{QK^T}{\sqrt{d_k}} ight)V\)
Chia cho \(\sqrt{d_k}\) để tránh việc tích vô hướng quá lớn khiến hàm softmax bị bão hòa (gradient quá nhỏ).

📌 Hình thái học (Morphology: Inflectional vs Derivational)
Inflectional Morphology (Hình thái học biến hình)
Biến đổi đuôi từ để biểu thị thì, số lượng, sở hữu nhưng KHÔNG LÀM THAY ĐỔI TỪ LOẠI.
Ví dụ: walk ➔ walked (đều là Verb), book ➔ books (đều là Noun).
Derivational Morphology (Hình thái học phái sinh)
Thêm tiền tố/hậu tố tạo ra từ mới hoặc LÀM THAY ĐỔI TỪ LOẠI.
Ví dụ: teach (Verb) ➔ teacher (Noun), happy (Adj) ➔ unhappy (trái nghĩa) / happiness (Noun).
📌 Topic Modeling: Latent Dirichlet Allocation (LDA)
Mô hình xác suất sinh chủ đề LDA
Mỗi văn bản là một phân phối xác suất trên các chủ đề (\( heta \sim ext{Dirichlet}(lpha)\)), và mỗi chủ đề là một phân phối xác suất trên các từ vựng (\(\phi \sim ext{Dirichlet}(eta)\)).
- \(lpha\) cao: Văn bản nói về nhiều chủ đề hỗn hợp; \(lpha\) thấp: Văn bản chỉ xoay quanh 1-2 chủ đề đặc thù.
- \(eta\) cao: Chủ đề chứa nhiều từ vựng; \(eta\) thấp: Chủ đề tập trung vào các từ vựng rất chuyên biệt.
📌 Ngữ đoạn & Tham chiếu (Discourse & Coreference Resolution)
Anaphora Resolution & Cohesion vs Coherence
Anaphora: Giải quyết đại từ thay thế (như he, she, it) trỏ về thực thể tiền đề (Antecedent) nào xuất hiện trước đó.
Cohesion: Sự liên kết hình thức ngữ pháp và từ ngữ giữa các câu.
Coherence: Tính mạch lạc, logic về mặt ngữ nghĩa của toàn bộ đoạn văn bản.

📐 Bảng tổng hợp công thức toán học cần thuộc khi thi FE
1. N-gram Maximum Likelihood Estimation (MLE)
\(P(w_n | w_1, \dots, w_{n-1}) = rac{C(w_1, \dots, w_n)}{C(w_1, \dots, w_{n-1})}\)
2. Làm mượt Laplace (Add-1 Smoothing)
\(P_{ ext{Laplace}}(w_i | w_{i-1}) = rac{C(w_{i-1}, w_i) + 1}{C(w_{i-1}) + |V|}\)
3. Perplexity (Độ phức tạp ngôn ngữ)
\(PP(W) = \sqrt[N]{ rac{1}{\prod_{i=1}^N P(w_i | w_{i-1})}}\)
4. TF-IDF (Tần suất từ & Nghịch đảo tần suất văn bản)
\( ext{TF}(t, d) = rac{f_{t, d}}{\sum_{t'} f_{t', d}}, \quad ext{IDF}(t, D) = \log\left( rac{|D|}{|\{d \in D : t \in d\}|} ight)\)
5. HMM Viterbi Dynamic Programming Transition
\(v_t(j) = \max_{i=1}^{N} \left[ v_{t-1}(i) \cdot a_{ij} ight] \cdot b_j(o_t)\)
6. Độ đo phân loại Precision, Recall & F1-Score
\( ext{Precision} = rac{ ext{TP}}{ ext{TP} + ext{FP}}, \quad ext{Recall} = rac{ ext{TP}}{ ext{TP} + ext{FN}}, \quad F_1 = 2 imes rac{P imes R}{P + R}\)
